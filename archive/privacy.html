개인정보 안내 · Privacy

2026-10-22 · 한국어 · English · 日本語 · 简体中文

한국어

아카이브를 볼 때 Google 로그인이나 번역 API 키는 필요 없습니다. 공개되는 자료는 공유자가 동의한 자막 원문·번역·시간·화면 위치·표시 설정과 원본 YouTube 영상 ID·제목·채널·등록일입니다. 원본 영상 파일, PC 경로와 번역 API 키는 수집하지 않습니다. 공유할 권한이 있는 자막만 등록하고 개인정보를 넣지 마세요.

웹 화면은 GitHub Pages, 자막 파일은 운영자의 Google Drive, 목록과 접수 기능은 Oracle 서버를 사용합니다. 각 제공자는 서비스를 위해 접속 정보를 처리할 수 있습니다. 남용 제한을 위해 원본 IP 대신 비밀값으로 변환한 식별값과 일별 횟수를 사용하며 2일 이전의 카운터는 다음 등록 요청 때 정리합니다. 운영 서버의 접속 로그에는 IP가 남을 수 있습니다.

자막은 공유 취소 또는 운영자 삭제 전까지 보관합니다. 공유한 PC의 완료 작업에서 ‘공유 등록 취소’를 누르면 공개 목록과 재요청을 차단하고 Drive 파일을 비공개 휴지통으로 옮깁니다. 운영 기록은 남을 수 있고 이미 전달된 자막의 사본은 회수할 수 없습니다. 작업 기록만 삭제하면 공유 등록은 유지되므로 먼저 공유를 취소하세요. 공유 관리용 비밀값은 본인 PC에 보관하며 서버에는 해시만 보관합니다.

Google 연결은 운영자 계정에만 필요합니다. 요청 범위는 앱이 만들거나 사용자가 선택한 Drive 파일에 대한 drive.file입니다. 연결 토큰과 클라이언트 비밀정보는 운영 서버의 비공개 파일로 보관하며 브라우저 확장이나 공개 배포에 포함하지 않습니다. Google 계정의 연결된 앱 설정에서 권한을 취소할 수 있습니다.

오역 신고는 기존 프로젝트 비공개 신고 서버에서 검토합니다. 공개 게시물 삭제 문의는 프로젝트 문의로 해주세요. 문의에 API 키나 개인정보를 적지 마세요.

English

Viewing requires no Google login or translation API key. Consented public data includes subtitle source and translation, timing, screen placement and display settings, plus the original YouTube video ID, title, channel and publication date. Original video files, PC paths and translation API keys are excluded. Share only subtitles you have permission to publish, without personal information.

GitHub Pages hosts the website, the operator’s Google Drive stores captions, and Oracle hosts the index and intake. Providers may process connection data. Abuse counters use a secret-derived IP identifier instead of raw IPs; counters older than two days are cleared on subsequent submissions. Operational access logs may contain IP addresses.

Captions remain until unshared or removed by the operator. Choose Unshare in the originating PC job to hide the listing, block further retrieval and move the Drive file to private Trash. Operational records may remain. Copies already delivered cannot be recalled. Deleting local job history does not unshare a post: unshare it first. The management secret stays on the originating PC; only its hash is stored on the server.

Only the operator connects a Google account. The drive.file scope covers files created by the app or explicitly selected by the user. Tokens and client secrets stay in private server files and are excluded from extensions and public distributions. Access can be revoked in the Google account’s connected-app settings.

Translation reports use the project’s existing private review service. Contact the project for public-post removal. Never include API keys or personal information in public issues.

日本語

閲覧にGoogleログインや翻訳APIキーは不要です。同意のうえ公開する情報は字幕の原文・訳文・時間・画面位置・表示設定、元のYouTube動画ID・タイトル・チャンネル・登録日時です。元動画ファイル、PCのパス、翻訳APIキーは収集しません。公開する権利のある字幕のみ登録し、個人情報を含めないでください。

画面はGitHub Pages、字幕は運営者のGoogle Drive、一覧と受付はOracleで提供します。各提供者が接続情報を処理する場合があります。不正利用の制限には生のIPの代わりに秘密値から生成した識別子と日別回数を使用し、2日より古いカウンターは次の登録時に削除します。運用ログにIPが記録される場合があります。

共有取消または運営者による削除まで保管します。共有元PCの完了した作業で「共有を取り消す」を選ぶと一覧と再取得を停止し、Driveファイルを非公開のゴミ箱に移します。運用記録が残る場合があり、配信済みのコピーは回収できません。作業履歴の削除だけでは公開は取り消されないため、先に共有を取り消してください。管理用秘密値は元PC、サーバーにはそのハッシュのみを保管します。

Google連携は運営者のみが行います。drive.file権限はアプリで作成したか、利用者が明示的に選択したファイルが対象です。トークンとクライアント秘密情報はサーバーの非公開ファイルに保管し、拡張機能や公開配布物に含めません。Googleアカウントの連携アプリ設定から権限を取り消せます。

誤訳報告は既存の非公開受付で確認します。公開投稿の削除相談はプロジェクトへ。公開の問い合わせにAPIキーや個人情報を書かないでください。
