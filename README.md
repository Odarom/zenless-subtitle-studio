# Zenless Subtitle Studio 0.4.0

[한국어](README-ko.md) · [English](README-en.md) · [日本語](README-ja.md) · [简体中文](README-zh-CN.md)

[Download for Windows x64 / Windows 다운로드](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

Translate a complete YouTube video or local file before playback. Optional local speech/OCR, a shared Zenless glossary, one whole-video translation request by default, and private in-app feedback. Each user supplies their own translation API key.

Extract the entire release ZIP and run **Start.cmd**. Node is included; speech/video tools download on first launch. Load the included **video-extension** folder in Chrome/Edge for YouTube overlays.

Recommended: a [Google AI Studio free API key](https://aistudio.google.com/apikey) with **Gemini 3.1 Flash-Lite** (`gemini-3.1-flash-lite`), subject to service quotas. See the language guides for setup, privacy and updates.
