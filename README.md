## 한국어

공유 자막 감상만 하려면 [아카이브 사용법](README-ko.md#archive-viewer)을 보세요. 확장만 있으면 되며 PC 작업실·API 키는 필요 없습니다.

유튜브·로컬 영상의 인식과 번역을 마친 뒤 완성된 자막을 봅니다.

**[Windows 프로그램 다운로드](https://github.com/Odarom/zenless-subtitle-studio/releases/download/v0.7.1/zenless-subtitle-studio-0.7.1-win-x64.zip)**

1. ZIP을 모두 풀고 **Start.cmd**를 실행합니다.
2. 열린 프로그램의 **왼쪽 메뉴 → API 및 연결 설정**에서 본인 API 키를 저장합니다.
3. **영상 번역**에서 영상과 언어를 선택하고 **자막 만들기**를 누릅니다. 화면 OCR은 선택 사항이며 기본 꺼짐입니다.

**[오역 신고로 번역 품질 개선하기](README-ko.md#오역-신고로-번역-품질-개선하기)** — 게임 용어·약어·번역 오류를 알려주세요. 신고를 검토해 젠레스 게임 용어 DB와 번역 품질을 개선합니다.

본인 영상 파일도 **미리보기로 장면을 보며 자막 수정·삭제·오역 신고**를 할 수 있습니다. [→ 미리보기 사용법](README-ko.md#본인-영상-파일-번역과-미리보기)

## English

For shared captions only, see the [archive guide](README-en.md#archive-viewer). Only the extension is required; no PC studio or API key.

Recognize and translate a YouTube or local video, then watch with finished subtitles.

**[Download for Windows](https://github.com/Odarom/zenless-subtitle-studio/releases/download/v0.7.1/zenless-subtitle-studio-0.7.1-win-x64.zip)**

1. Extract all files and run **Start.cmd**.
2. Save your key under **Left menu → API & connection** in the program page.
3. In **Translate video**, select a video and languages, then **Create subtitles**. Screen OCR is optional and off by default.

**[Report errors to improve translation quality](README-en.md#report-errors-to-improve-translation-quality)** — Found an incorrect game term, abbreviation or translation? Reports are reviewed to improve the Zenless game terminology DB and translation quality.

For your own video files, **use the preview to check scenes, edit or delete subtitles, and report translation errors**. [→ Preview guide](README-en.md#translate-and-preview-your-own-video)

[English installation and usage](README-en.md) · [Connect the YouTube extension](README-en.md#watch-on-youtube)

## 日本語

共有字幕の視聴のみなら[アーカイブの使い方](README-ja.md#archive-viewer)をご覧ください。拡張機能のみで利用でき、PC作業室・APIキーは不要です。

YouTube・ローカル動画を認識・翻訳し、完成した字幕で視聴します。

**[Windows版をダウンロード](https://github.com/Odarom/zenless-subtitle-studio/releases/download/v0.7.1/zenless-subtitle-studio-0.7.1-win-x64.zip)**

1. ZIPをすべて展開し、**Start.cmd**を実行します。
2. 開いた画面の**左メニュー → API・接続設定**で自分のキーを保存します。
3. **動画を翻訳**で動画と言語を選び、**字幕を作成**します。画面OCRは任意で、初期状態はオフです。

**[誤訳を報告して翻訳品質を改善する](README-ja.md#誤訳を報告して翻訳品質を改善する)** — ゲーム用語・略語・翻訳の誤りをお知らせください。報告を確認し、ゼンレスのゲーム用語DBと翻訳品質の改善に役立てます。

自分の動画ファイルも、**プレビューで場面を見ながら字幕の修正・削除・誤訳報告**ができます。 [→ プレビューの使い方](README-ja.md#自分の動画ファイルを翻訳プレビューする)

[日本語の導入・使い方](README-ja.md) · [YouTube拡張機能の接続](README-ja.md#youtubeで字幕を見る)

## 简体中文

仅观看共享字幕请查看[档案馆使用说明](README-zh-CN.md#archive-viewer)。只需扩展，无需PC工作室或API密钥。

完成YouTube或本地视频的识别和翻译后，使用生成的字幕观看。

**[下载Windows程序](https://github.com/Odarom/zenless-subtitle-studio/releases/download/v0.7.1/zenless-subtitle-studio-0.7.1-win-x64.zip)**

1. 完整解压ZIP并运行**Start.cmd**。
2. 在程序页面的**左侧菜单 → API 与连接设置**保存自己的密钥。
3. 在**翻译视频**选择视频及语言，点击**生成字幕**。屏幕OCR可选，默认关闭。

**[举报误译，帮助改进翻译质量](README-zh-CN.md#举报误译帮助改进翻译质量)** — 发现游戏术语、缩写或翻译错误？我们会审核举报，用于改进绝区零游戏术语数据库和翻译质量。

自己的视频文件也可以**在预览画面时修改、删除字幕或举报误译**。 [→ 预览使用方法](README-zh-CN.md#翻译并预览自己的视频文件)

[简体中文安装与使用](README-zh-CN.md) · [连接YouTube扩展](README-zh-CN.md#在youtube观看字幕)
