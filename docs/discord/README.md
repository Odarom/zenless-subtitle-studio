## 한국어

언어별 Discord 채널을 본인 API 키로 번역합니다.

**[봇 설치](https://discord.com/oauth2/authorize?client_id=1557261995215028254) · [PC 연결 프로그램 다운로드](https://github.com/Odarom/zenless-discord-translator/releases/download/v0.3.2/zenless-discord-runner-0.3.2-win-x64.zip)**

1. ZIP을 모두 풀고 **Start.cmd**를 실행합니다.
2. 열린 설정 화면에서 API 키를 저장하고 Discord의 **/zzz connect** 코드로 연결합니다.
3. **/zzz link**로 언어 채널을 같은 그룹에 연결하고 프로그램을 켜 둡니다.

[한국어 설치·사용법](README-ko.md) · [키 변경](README-ko.md#설정-화면-다시-열기--키-변경) · [서버 설치](HOSTING.md#한국어)

## English

Translate language channels using your own API key.

**[Install the bot](https://discord.com/oauth2/authorize?client_id=1557261995215028254) · [Download the PC runner](https://github.com/Odarom/zenless-discord-translator/releases/download/v0.3.2/zenless-discord-runner-0.3.2-win-x64.zip)**

1. Extract all ZIP files and run **Start.cmd**.
2. Save your API key in the settings page and pair with the code from **/zzz connect** in Discord.
3. Connect language channels to one group with **/zzz link** and keep the runner running.

[English installation and usage](README-en.md) · [Server setup](HOSTING.md#english)
