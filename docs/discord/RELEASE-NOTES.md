## English

Expanded hosting, data-flow, terms, privacy and glossary explanations to four languages and changed display names to ZZZ. GitHub addresses and pairing behavior are unchanged. Extract the whole ZIP and run Start.cmd.

Server profiles, keys, models and limits remain on your own device. Stop/save/start only the profile whose key you change. Supports personal servers, multiple profiles, automatic glossary updates and private reports. Stop before replacing code and preserve your existing installation's app/data privately. Never distribute a folder containing personal settings. [English guide](README-en.md).
