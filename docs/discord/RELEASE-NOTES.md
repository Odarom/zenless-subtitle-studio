# ZZZ Discord Runner 0.3.3

[한국어](README-ko.md) · [English](README-en.md) · [日本語](README-ja.md) · [简体中文](README-zh-CN.md)

## 한국어

게임 용어·약어·번역 오류를 알려주세요. 신고를 검토해 젠레스 게임 용어 DB와 번역 품질을 개선합니다.

디스코드 번역 메시지에 !report로 답장 → 신고 시작 → 원문 확인 → 신고 작성.

신고 내용을 작성한 뒤 전송 내용을 확인하고 ‘동의하고 보내기’를 누르면 프로젝트 관리자에게 바로 전달됩니다.

## English

Found an incorrect game term, abbreviation or translation? Reports are reviewed to improve the Zenless game terminology DB and translation quality.

Reply to a Discord translation with !report → Start report → check the original → Write report.

After writing your report, review the contents and choose Agree and send to deliver it directly to the project maintainer.

## 日本語

ゲーム用語・略語・翻訳の誤りをお知らせください。報告を確認し、ゼンレスのゲーム用語DBと翻訳品質の改善に役立てます。

Discordの訳文に !report と返信 → 報告を開始 → 原文を確認 → 報告を作成。

報告を作成し、送信内容を確認して「同意して送信」を押すと、プロジェクト管理者へ直接届きます。

## 简体中文

发现游戏术语、缩写或翻译错误？我们会审核举报，用于改进绝区零游戏术语数据库和翻译质量。

回复Discord译文并发送 !report → 开始举报 → 确认原文 → 填写举报。

填写举报后确认发送内容，点击“同意并发送”即可直接发送给项目维护者。
