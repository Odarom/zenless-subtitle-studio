공개 Discord 봇은 원문·최근 문맥과 번역 결과를 중계합니다. 사용자가 자신의 PC 또는 개인 서버에서 번역 연결 프로그램을 실행하고, 자신의 API 계정·키로 번역 API를 직접 호출합니다. 공용 봇은 다른 이용자의 번역 API 키를 받거나 보관하지 않습니다. 키를 Discord나 신고에 보내지 마세요. 사용자가 관리하는 기기의 관리자·호스팅 사업자가 해당 기기의 데이터에 접근할 가능성은 별도입니다.

채널 관리자와 참여자는 원문·문맥이 다른 언어 채널 및 연결 기기, 선택한 API 제공사로 처리되는 범위를 확인해야 합니다. 개인정보·비밀·타인의 권리를 침해하는 자료를 전송하지 마세요. API 계정과 키, 무료 구간·사용 한도·요금·연령·지역·데이터 이용 조건은 해당 제공사의 정책을 따릅니다. 이 프로그램의 요청 횟수 제한은 결제 금액 한도가 아니며 API 이용 조건을 대신하거나 허용 여부를 보증하지 않습니다.

제출한 오역 신고는 비공개 검토와 공용 DB 개선에 사용되며 필요 시 AI로 대조할 수 있습니다. 사용자 제공 내용은 검증 전 자료이며 자동 승인되지 않습니다. 개인 정보와 무관한 검토된 용어·번역 규칙만 공개 DB에 반영합니다. 악용·과도한 요청은 제한할 수 있습니다. 번역 정확도·연속 가동·무료 서비스의 지속은 보장하지 않습니다. 법률상 배제할 수 없는 권리를 제한하지 않습니다.
