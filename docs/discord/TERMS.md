The public bot does not accept or store other users' translation API keys. Never submit keys through Discord or reports. Channel administrators and participants must understand sharing with linked channels, the paired runner and selected API providers. Submitted reports support private review and glossary corrections and may be compared using AI. Translation accuracy, uninterrupted operation and continued free provider access are not guaranteed. Non-excludable legal rights remain unaffected.

Independent installations have their own operator. Legacy API_MODE=server allows that operator to decrypt saved keys and should be restricted to personal use with the operator's own key. It is distinct from the public broker. Changes are dated here and in release notes. See [Privacy](PRIVACY.md) for processing and retention.
