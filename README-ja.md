# ZZZ字幕スタジオ

[한국어](README-ko.md) · [English](README-en.md) · [日本語](README-ja.md) · [简体中文](README-zh-CN.md)

YouTubeやローカル動画の認識・翻訳が完了してから、できあがった字幕で視聴するWindows用アプリです。

**[Windows x64版をダウンロード・0.7.0](https://github.com/Odarom/zenless-subtitle-studio/releases/download/v0.7.0/zenless-subtitle-studio-0.7.0-win-x64.zip)** · [最新リリース](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

## 導入して字幕を作る

1. ZIPを**すべて展開**し、**Start.cmd**を実行します。Node.jsは同梱済みです。初回は音声・動画ツールとモデルを取得するため、インターネット接続と準備時間が必要です。
2. ブラウザーに開く**ZZZ字幕スタジオ**の左メニューから**API・接続設定**を選び、サービス・モデル・自分のAPIキーを入力して保存します。
3. **動画を翻訳**でYouTube URLまたは動画・音声・SRT/VTTファイルを指定し、原語と翻訳先を選びます。
4. 認識方法を選びます。**YouTube字幕を使わず音声から新しく作成**は標準でオン、画面OCRは標準でオフです。**翻訳せず原語字幕だけを保存**では翻訳APIを呼び出しません。
5. **字幕を作成**して完了を待ち、訳文を確認して保存または動画に適用します。

**作業室**とはStart.cmdでブラウザーに開くアプリの画面です。利用中は実行ウィンドウを開いたままにしてください。処理は自分のPCで行い、別の動画処理サーバーは不要です。

## 誤訳を報告して翻訳品質を改善する

ゲーム用語・略語・翻訳の誤りをお知らせください。報告を確認し、ゼンレスのゲーム用語DBと翻訳品質の改善に役立てます。

1. **YouTube・ローカル動画のプレビュー：** 音声字幕または画面翻訳をクリックし、**誤訳を報告**を選びます。YouTubeでは先にPC作業室に接続し、完了した作業を適用してください。
2. **字幕一覧：** 完了した作業の**字幕の確認・編集**で**音声字幕 / 画面の文字**を選び、該当区間の**誤訳を報告**を押します。
3. 誤っている部分を説明し、**報告を送信**します。修正案は分かる場合のみで構いません。**受付番号**が表示されたら送信完了です。

正しい訳が分からなくても、誤っている部分をお知らせください。GitHubへのログインは不要で、非公開で受け付けます。

プログラムを使わなくても、[正式名称・略語を直接報告](https://github.com/Odarom/zenless-translation-database/issues/new/choose)できます。このGitHub経由の報告にはアカウントが必要で、内容は公開されます。

## 自分の動画ファイルを翻訳・プレビューする

YouTube以外の**自分の動画ファイルも翻訳し、プレビューを見ながら字幕の修正・誤訳報告**ができます。実際の場面と字幕を照らし合わせて確認する方法をおすすめします。

1. **動画を翻訳 → ファイルを開く**で動画を選び、翻訳を完了します。
2. 完了した作業で**ローカル動画で字幕をプレビュー**を押し、**翻訳に使った同じ元動画**を選びます。
3. 音声字幕または画面翻訳をクリックすると再生が止まり、**字幕を削除・誤訳を報告**のメニューが開きます。**文章はプレビュー下の「字幕の確認・編集」にある翻訳入力欄**で修正します。修正内容はプレビューにすぐ反映されます。
4. 確認後に**VTTを保存 ↓**または**プロジェクトJSON ↓**で修正内容と調整した音声字幕の位置を保存します。**SRTを保存 ↓**には内容と時間だけが含まれます。未保存の文章修正もダウンロード前に保存されます。

自分の動画をプレビューする場合、YouTube拡張機能は不要です。ブラウザーで再生できない形式は、外部プレーヤーで動画と字幕を確認し、作業室の字幕一覧で修正・報告してください。

## YouTubeで字幕を見る

1. Chrome/Edgeの拡張機能管理で**デベロッパーモード → 展開済み拡張機能を読み込む**を選び、同梱の**video-extension**フォルダーを指定します。
2. **作業室の左メニュー → API・接続設定 → YouTube拡張機能を接続**で**PC接続コードをコピー**を押します。
3. YouTube動画を開き、ブラウザー右上の**ZZZ字幕スタジオの拡張アイコン**を押します。**PC接続コード**欄に貼り付けて**接続**します。翻訳APIキーとは別です。
4. **完成した字幕**から対象動画の作業を選び、**選択した字幕を適用**します。

## 共有字幕アーカイブ

[共有字幕アーカイブ](https://odarom.github.io/zenless-subtitle-studio/archive/)で動画を探し、**YouTubeで見る（拡張機能が必要）**を選びます。字幕は登録された制作者の元のYouTube動画でのみ適用されます。サイト内の動画再生や字幕ダウンロードはありません。

**視聴のみの場合：**ZIPを展開し、Chrome/Edgeに **video-extension** フォルダーを読み込みます。**Start.cmdの実行、PC作業室への接続、翻訳APIキー、Googleログインは不要です。** 拡張を0.7.0以降に再読み込みし、YouTubeも更新してください。

**共有する場合：**PC作業室の完了したYouTube作業で **アーカイブに共有**を選び、表示設定と公開への同意を確認します。未保存の字幕編集・位置は先に保存します。字幕・元動画情報・表示設定が公開され、動画ファイル・APIキー・PCパスは送信しません。公開する権利のある字幕のみ共有してください。[プライバシー](https://odarom.github.io/zenless-subtitle-studio/archive/privacy.html#ja)

共有元PCの **共有を取り消す** で掲載を終了できます。履歴の削除だけでは公開は取り消されないため、**先に共有を取り消してください。** 配信済みのコピーは回収できず、複製自体も防げません。視聴者の編集・非表示は元の共有ファイルを変更しません。共有字幕のクリックから非公開の誤訳報告も送れます。

**動画の容量だけ整理：**完了したYouTube作業の **一時動画を削除（MB）** は画面解析用動画と動画保存用のコピーのみ削除します。字幕・編集・履歴・別途ダウンロードしたファイルは保持します。YouTubeでの字幕視聴は継続でき、再度動画を保存すると新しくダウンロードします。

## 保存・編集

音声・画面字幕の背景は拡張設定とプレビューで個別に切り替えられます。視聴用の設定で、ダウンロードファイルのスタイルは変わりません。

- 音声字幕にマウスを重ねて表示される **↕ 移動** ハンドルを上下にドラッグすると、すべての音声字幕の高さが変わります。字幕のクリックでは従来どおり報告・削除メニューが開きます。拡張設定とプレビューの **音声字幕の高さ / 位置をリセット** でも調整できます。高さは接続した作業に自動保存されます。VTTとプロジェクトJSONには調整した位置が、SRTには内容と時間のみが反映されます。文章の修正もダウンロード前に保存されます。再生コントロールの表示中は、画面字幕の重なった部分だけクリックを再生バーに通し、字幕の残りの部分は引き続きクリックできます。

- 保存対象の標準は**音声字幕 + 画面字幕**で、**音声のみ / 画面のみ**も選べます。SRT/VTTは通常の字幕用、プロジェクトJSONは画面位置を保持して拡張機能へ読み込む用途です。
- 確認一覧や動画上の字幕をクリックして**削除・誤訳報告**できます。削除分は**削除した字幕**から復元できます。報告は非公開で、GitHubログインは不要です。
- 完了したYouTube作業の**YouTube動画を保存 ↓**から動画を別途保存できます。字幕は別ファイルで保存してください。
- **作業履歴を削除**すると、その作業用にアプリが保存した動画・音声のコピーと生成・中間ファイルも整理します。PC上の原本と別途保存した動画・字幕は保持します。

## API設定と更新

Gemini・OpenAI・DeepL API Free/Pro・Ollamaに対応します。**2026-10-19韓国時間に記載した無料APIの推奨**は[Google AI Studio](https://aistudio.google.com/apikey)の**Gemini 3.1 Flash-Lite**（<code>gemini-3.1-flash-lite</code>）です。アカウント・プロジェクトの[無料枠の条件と上限](https://ai.google.dev/gemini-api/docs/pricing)を確認してください。Ollamaは別途導入とモデル準備が必要です。

キー変更は**左メニュー → API・接続設定**で保存します。キーは自分のPCに保管します。同じ設定画面でアプリ本体と用語集の更新を確認できます。

**拡張機能は手動で再読み込みが必要です。** アプリ内のプログラム更新後、Chromeでは `chrome://extensions`、Edgeでは `edge://extensions` を開きます。ZZZ拡張機能の **↻ 再読み込み**を押し、YouTubeページを **F5で再読み込み**してから、拡張機能で**選択した字幕を適用**をもう一度押してください。ZIPを**別のフォルダーに新しく展開した場合**は、古いフォルダーの拡張機能を無効にし、新しい **video-extension** を**展開済み拡張機能を読み込む**で指定して、**PC接続コード**を再登録します。

同じフォルダに更新した場合は、ブラウザを完全に終了して再起動するか、PCを再起動しても拡張の新しいファイルが反映されます。その後YouTubeページを更新し、字幕を再適用してください。
