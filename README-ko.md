# ZZZ 자막 작업실

[한국어](README-ko.md) · [English](README-en.md) · [日本語](README-ja.md) · [简体中文](README-zh-CN.md)

유튜브 주소나 영상 파일을 넣고 인식·번역을 마친 뒤, 완성된 자막을 감상하는 Windows PC 프로그램입니다.

**[Windows x64 다운로드 · 0.6.8](https://github.com/Odarom/zenless-subtitle-studio/releases/download/v0.6.8/zenless-subtitle-studio-0.6.8-win-x64.zip)** · [최신 배포 페이지](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

## 설치하고 자막 만들기

1. ZIP을 **모두 압축 해제**하고 **Start.cmd**를 실행합니다. Node.js는 포함되어 있습니다. 첫 실행에는 음성·영상 도구와 모델을 다운로드하므로 인터넷 연결과 준비 시간이 필요합니다.
2. 브라우저에 열린 **ZZZ 자막 작업실**의 왼쪽 메뉴에서 **API 및 연결 설정**을 누릅니다. 번역 서비스·모델·본인 API 키를 입력하고 저장합니다.
3. **영상 번역**에서 유튜브 주소를 넣거나 영상·음성·SRT/VTT 파일을 선택합니다. 원어와 번역 언어를 고릅니다.
4. 필요한 인식 옵션을 선택합니다. **유튜브 자막을 쓰지 않고 음성으로 새로 만들기**는 기본 켜짐, **화면 글자 인식(OCR)**은 기본 꺼짐입니다. **번역 없이 원어 자막만 저장하기**를 켜면 번역 API를 호출하지 않습니다.
5. **자막 만들기**를 누르고 완료를 기다립니다. 완료 후 원문·번역을 확인하고 자막을 저장하거나 영상에 적용하세요.

여기서 **작업실**은 Start.cmd 실행 후 브라우저에 열리는 프로그램 화면입니다. 사용하는 동안 실행 창을 켜 두세요. 처리는 각자 PC에서 하며 별도 영상 처리 서버는 필요 없습니다.

## 유튜브에서 자막 보기

1. Chrome/Edge 확장 관리 화면에서 **개발자 모드 → 압축해제된 확장 프로그램 로드**를 선택하고, 함께 받은 **video-extension** 폴더를 불러옵니다.
2. **작업실 왼쪽 메뉴 → API 및 연결 설정 → 유튜브 확장 프로그램 연결 → PC 연결 코드 복사**를 누릅니다.
3. 유튜브 영상을 열고 브라우저 오른쪽 위의 **ZZZ 자막 작업실 확장 아이콘**을 누릅니다. **PC 연결 코드**를 붙여 넣고 **연결**을 누릅니다. 번역 API 키를 넣는 칸이 아닙니다.
4. **완료된 자막**에서 해당 영상의 작업을 고르고 **선택한 자막 적용**을 누릅니다.

로컬 영상은 작업실의 미리보기에서 확인합니다. 브라우저가 재생하지 못하는 영상은 자막 파일과 함께 외부 플레이어에서 여세요.

## 자막·영상 저장과 수정

- 음성 자막에 마우스를 올리면 나타나는 **↕ 이동** 손잡이를 위아래로 끌면 모든 음성 자막의 높이가 함께 바뀝니다. 클릭하면 기존 신고·삭제 메뉴가 열립니다. 확장 설정이나 미리보기의 **음성 자막 높이 / 기본 위치**로도 조절할 수 있습니다. 높이는 연결된 작업에 자동 저장됩니다. VTT·프로젝트 JSON에는 조절한 위치가, SRT에는 내용·시간만 반영됩니다. 문구 수정도 다운로드 전에 저장됩니다. 재생바가 보일 때에는 겹친 화면 번역의 해당 부분만 클릭을 통과시켜 재생 조작을 우선합니다. 자막의 나머지 부분은 계속 클릭할 수 있습니다.

- 저장 대상의 기본값은 **음성 자막 + 화면 자막**입니다. **음성 자막만 / 화면 자막만**도 선택할 수 있습니다. SRT·VTT는 일반 자막용, 프로젝트 JSON은 화면 위치까지 보존해 확장에서 불러올 때 사용합니다.
- 번역 목록이나 영상 위의 자막을 클릭해 **삭제·오역 신고**를 할 수 있습니다. 삭제한 자막은 **삭제한 자막** 탭에서 복원합니다. 신고는 GitHub 로그인 없이 비공개로 접수됩니다.
- 완료된 유튜브 작업의 **유튜브 영상 저장 ↓**로 영상을 따로 저장할 수 있습니다. 자막은 별도 파일로 저장하세요.
- **작업 기록 삭제**는 프로그램 안의 해당 영상·음성 사본과 생성·중간 파일도 정리합니다. PC 원본과 별도로 다운로드한 영상·자막은 유지합니다.

## API 설정과 업데이트

Gemini·OpenAI·DeepL API Free/Pro·Ollama를 지원합니다. **2026-10-19 한국시간 작성 기준 무료 API 추천**은 [Google AI Studio](https://aistudio.google.com/apikey)의 **Gemini 3.1 Flash-Lite**(<code>gemini-3.1-flash-lite</code>)이며, 계정·프로젝트의 [무료 조건과 한도](https://ai.google.dev/gemini-api/docs/pricing)를 확인하세요. Ollama는 별도 설치·모델 준비가 필요합니다.

키를 바꾸려면 **왼쪽 메뉴 → API 및 연결 설정**에서 저장하세요. 키는 본인 PC에 보관합니다. 프로그램 업데이트와 **용어집 업데이트**도 이 설정 화면에서 확인할 수 있습니다. 프로그램 업데이트 후에는 확장 관리 화면과 유튜브 페이지를 새로고침하세요.
