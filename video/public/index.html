인식할 내용

화면 인식은 선택 사항입니다. 처음 사용할 때 무료 CPU 인식 도구를 내려받습니다.

화면 인식 지원: 한국어·영어·일본어·중국어 간체/번체·러시아어. 번역 언어는 별도로 선택합니다.

1시간 영상도 처리할 수 있습니다. 짧게 나타나는 글자는 검사 간격에 따라 놓칠 수 있습니다.

영상은 전체 용어집을 기본으로 사용합니다. 작은 모델은 관련 용어만 직접 선택하세요. DeepL은 전체 DB를 로컬 용어 적용에 사용합니다.

음성 문장과 화면 글자, 용어집을 함께 보냅니다. 전체 요청이 너무 크면 전송 전에 안내하며 자동으로 분할하지 않습니다.

켜면 영상 소리를 PC에서 받아씁니다. 꺼두면 원어 자막(자동 생성 포함)을 먼저 사용하고, 없으면 음성을 인식합니다. 영상·음성 파일은 항상 음성 인식, SRT/VTT는 파일 내용을 사용합니다.

다른 언어로 번역하지 않고 원문을 저장합니다. 번역 API 호출·요금이 없습니다. 음성·화면 인식은 선택한 옵션에 따라 진행합니다.

번역 API를 먼저 설정하세요.

음성 인식 → 용어집 번역 → 자막 저장 → 감상

번역 API와 PC 연결

영상 번역용 설정입니다. 저장한 API 키는 화면에 다시 표시하지 않습니다.

번역 API

구조화된 출력을 지원하는 텍스트 모델을 선택하세요. 직접 입력할 수 있습니다.

기본은 분당 1회입니다. 다음 영상이나 선택한 분할 요청도 간격을 지킵니다. 한도 오류 뒤에 자동으로 재요청하지 않습니다.

한 묶음 번역이 한 요청입니다. 실패·재시도도 횟수에 포함되며 금액 한도는 아닙니다.

프로그램 업데이트

API 키·모델·작업 기록을 유지합니다. 번역 중에는 설치하지 않으며 실패하면 이전 파일로 복구합니다.

유튜브 확장 사용 시: 업데이트 후 확장 관리에서 ZZZ 확장을 ↻ 새로고침하거나 브라우저를 완전히 종료 후 다시 여세요. 컴퓨터 재시작도 가능합니다. 유튜브 페이지를 새로고침하고 자막을 다시 적용하세요.

용어집 업데이트

프로그램을 다시 설치하지 않고 GitHub의 검토된 용어집만 내려받을 수 있습니다.

새 용어집은 새 번역부터 사용합니다. 작업 중에는 업데이트하지 않으며, 실패하면 기존 용어집을 유지합니다.

유튜브 확장 프로그램 연결

확장 프로그램에서 아래 PC 연결 코드를 한 번 등록하면, 완성된 자막을 불러올 수 있습니다.

  1. Chrome/Edge의 확장 프로그램 관리 화면을 여세요.
  2. 개발자 모드를 켜고 압축해제된 확장 프로그램 로드를 선택하세요.
  3. 프로그램과 함께 받은 video-extension 폴더를 선택하세요. 개발 폴더에서는 dist → video-extension에 있습니다.
  4. 유튜브에서 확장 프로그램을 열고 연결 코드를 붙여 넣으세요.
