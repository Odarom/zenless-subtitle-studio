## 한국어

[한국어 사용법](README-ko.md) · [Windows 다운로드](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

유튜브 영상이나 로컬 파일을 선택해 인식·번역한 후 완성된 자막을 감상합니다. ZIP 전체를 풀고 Start.cmd를 실행하세요. Node.js는 포함되고 음성·영상 도구는 첫 실행에 내려받습니다. YouTube에는 포함된 video-extension을 등록합니다. 각자 API 키를 사용하고 화면 OCR은 선택 사항입니다. 개인 영상·작업 기록·API 키는 배포에 포함하지 않습니다.

[공용 용어집](https://github.com/Odarom/zenless-translation-database) · [Discord 봇](https://github.com/Odarom/zenless-discord-translator). 팬 제작 도구이며 게임 제작사의 공식 프로그램이 아닙니다.

## English

[English guide](README-en.md) · [Windows download](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

Choose a YouTube video or local file, complete recognition/translation, then watch with finished subtitles. Extract the whole ZIP and run Start.cmd. Node.js is included; speech/video tools download on first use. Load the included video-extension for YouTube. Use your own API key; screen OCR is optional. Releases contain no personal videos, job history or API keys.

[Shared glossary](https://github.com/Odarom/zenless-translation-database) · [Discord bot](https://github.com/Odarom/zenless-discord-translator). Fan-made software, not an official game product.

## 日本語

[日本語の使い方](README-ja.md) · [Windows版](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

YouTube動画またはローカルファイルを選び、認識と翻訳を終えてから完成した字幕で視聴します。ZIP全体を展開してStart.cmdを実行してください。Node.jsは同梱され、音声・動画ツールは初回に取得します。YouTubeでは同梱のvideo-extensionを導入します。自分のAPIキーを使用し、画面OCRは任意です。個人動画・作業履歴・APIキーを配布ファイルに含めません。

[共通用語集](https://github.com/Odarom/zenless-translation-database) · [Discordボット](https://github.com/Odarom/zenless-discord-translator)。ファン制作でありゲーム公式プログラムではありません。

## 简体中文

[简体中文指南](README-zh-CN.md) · [Windows下载](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

选择YouTube视频或本地文件，识别并翻译完成后使用字幕观看。完整解压ZIP并运行Start.cmd。已包含Node.js，语音和视频工具会在首次运行时下载。YouTube需加载随附的video-extension。使用自己的API密钥，画面OCR可选。发布文件不包含个人视频、任务记录或API密钥。

[共享术语表](https://github.com/Odarom/zenless-translation-database) · [Discord机器人](https://github.com/Odarom/zenless-discord-translator)。本工具为粉丝制作，并非游戏官方程序。
