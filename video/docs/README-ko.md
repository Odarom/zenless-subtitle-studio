# ZZZ 자막 작업실

[한국어](README-ko.md) · [English](README-en.md) · [日本語](README-ja.md) · [简体中文](README-zh-CN.md)

유튜브 주소나 영상 파일을 넣고 인식·번역을 마친 뒤, 완성된 자막을 감상하는 Windows PC 프로그램입니다.

**[Windows x64 다운로드 · 0.7.3](https://github.com/Odarom/zenless-subtitle-studio/releases/download/v0.7.3/zenless-subtitle-studio-0.7.3-win-x64.zip)** · [최신 배포 페이지](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

## 설치하고 자막 만들기

1. ZIP을 **모두 압축 해제**하고 **Start.cmd**를 실행합니다. Node.js는 포함되어 있습니다. 첫 실행에는 음성·영상 도구와 모델을 다운로드하므로 인터넷 연결과 준비 시간이 필요합니다.
2. 브라우저에 열린 **ZZZ 자막 작업실**의 왼쪽 메뉴에서 **API 및 연결 설정**을 누릅니다. 번역 서비스·모델·본인 API 키를 입력하고 저장합니다.
3. **영상 번역**에서 유튜브 주소를 넣거나 영상·음성·SRT/VTT 파일을 선택합니다. 원어와 번역 언어를 고릅니다.
4. 필요한 인식 옵션을 선택합니다. **유튜브 자막을 쓰지 않고 음성으로 새로 만들기**는 기본 켜짐, **화면 글자 인식(OCR)**은 기본 꺼짐입니다. **번역 없이 원어 자막만 저장하기**를 켜면 번역 API를 호출하지 않습니다.
5. **자막 만들기**를 누르고 완료를 기다립니다. 완료 후 원문·번역을 확인하고 자막을 저장하거나 영상에 적용하세요.

여기서 **작업실**은 Start.cmd 실행 후 브라우저에 열리는 프로그램 화면입니다. 사용하는 동안 실행 창을 켜 두세요. 처리는 각자 PC에서 하며 별도 영상 처리 서버는 필요 없습니다.

## 오역 신고로 번역 품질 개선하기

게임 용어·약어·번역 오류를 알려주세요. 신고를 검토해 젠레스 게임 용어 DB와 번역 품질을 개선합니다.

1. **유튜브·로컬 영상 미리보기:** 음성 자막이나 화면 번역을 클릭하고 **오역 신고**를 선택합니다. 유튜브에서는 PC 작업실에 연결해 완료된 작업을 적용하세요.
2. **자막 목록:** 완료된 작업의 **자막 확인 및 수정**에서 **음성 자막 / 화면 글자**를 고르고 해당 구간의 **오역 신고**를 누릅니다.
3. 잘못된 부분을 설명하고 **신고 보내기**를 누릅니다. 수정 제안은 아는 경우에만 적어도 됩니다. **접수 번호**가 표시되면 전송이 완료된 것입니다.

올바른 번역을 몰라도 잘못된 부분만 알려주세요. GitHub 로그인 없이 비공개로 접수됩니다.

프로그램을 사용하지 않아도 [공식 명칭·약어를 직접 신고](https://github.com/Odarom/zenless-translation-database/issues/new/choose)할 수 있습니다. 이 GitHub 신고는 계정이 필요하며 내용이 공개됩니다.

## 본인 영상 파일 번역과 미리보기

유튜브 영상이 아니어도 본인 영상 파일을 넣어 번역하고, **미리보기를 보며 자막을 수정하거나 오역을 신고**할 수 있습니다. 실제 장면과 자막을 함께 보며 확인하는 방법을 추천합니다.

1. **영상 번역 → 파일 불러오기**에서 본인 영상을 선택하고 번역을 완료합니다.
2. 완료된 작업에서 **로컬 영상으로 자막 미리보기**를 누르고, **번역에 사용한 같은 원본 영상**을 선택합니다.
3. 영상을 보다가 음성 자막이나 화면 번역을 클릭하면 재생이 멈추고 **자막 삭제·오역 신고** 메뉴가 열립니다. **문구 수정은 미리보기 아래 ‘자막 확인 및 수정’의 번역 입력칸**에서 합니다. 수정 내용은 미리보기에 바로 표시됩니다.
4. 확인을 마치면 **VTT 저장 ↓** 또는 **프로젝트 JSON ↓**로 수정 내용과 조절한 음성 자막 위치를 저장합니다. **SRT 저장 ↓**에는 내용과 시간만 포함됩니다. 다운로드 시 남은 수정 내용도 저장됩니다.

본인 영상의 미리보기에는 유튜브 확장 프로그램을 설치할 필요가 없습니다. 브라우저에서 재생하지 못하는 형식은 외부 플레이어로 영상·자막을 확인하고 작업실의 자막 목록에서 수정·신고하세요.

## 유튜브에서 자막 보기

1. Chrome/Edge 확장 관리 화면에서 **개발자 모드 → 압축해제된 확장 프로그램 로드**를 선택하고, 함께 받은 **video-extension** 폴더를 불러옵니다.
2. **작업실 왼쪽 메뉴 → API 및 연결 설정 → 유튜브 확장 프로그램 연결 → PC 연결 코드 복사**를 누릅니다.
3. 유튜브 영상을 열고 브라우저 오른쪽 위의 **ZZZ 자막 작업실 확장 아이콘**을 누릅니다. **PC 연결 코드**를 붙여 넣고 **연결**을 누릅니다. 번역 API 키를 넣는 칸이 아닙니다.
4. **완료된 자막**에서 해당 영상의 작업을 고르고 **선택한 자막 적용**을 누릅니다.

## 공유된 자막 아카이브

[공유된 자막 아카이브 열기](https://odarom.github.io/zenless-subtitle-studio/archive/)에서 영상을 찾아 **유튜브에서 바로보기(확장 필요)**를 누르세요. 자막은 등록된 원작자의 YouTube 영상에서만 적용됩니다. 아카이브에는 영상 재생·자막 다운로드 기능이 없습니다.

**감상만 할 때:** ZIP을 풀고 Chrome/Edge에서 **video-extension** 폴더를 확장으로 불러오면 됩니다. **Start.cmd 실행·PC 작업실 연결·번역 API 키·Google 로그인은 필요 없습니다.** 확장은 0.7.0 이상으로 새로고침하고 YouTube 페이지도 새로고침하세요.

**직접 공유할 때:** PC 작업실의 완료된 YouTube 작업 상세 또는 **작업 기록 카드**에서 **아카이브에 공유**를 누르고 표시 설정과 공개 동의를 확인합니다. 저장하지 않은 자막 수정과 위치도 먼저 저장해 공유합니다. 공개되는 자료는 자막·원본 영상 정보·표시 설정이며, 원본 영상 파일·API 키·PC 경로는 포함하지 않습니다. 공유할 권한이 있는 자막만 올리세요. [개인정보 안내](https://odarom.github.io/zenless-subtitle-studio/archive/privacy.html#ko)

공유한 PC에서 **공유 등록 취소**로 게시를 내릴 수 있습니다. 작업 기록 삭제만으로는 공유가 취소되지 않으므로 **먼저 공유를 취소**하세요. 이미 받은 자막의 복사 자체를 막거나 회수할 수는 없습니다. 다른 사람이 수정·숨긴 자막은 원래 공유 파일을 바꾸지 않습니다. 공유 자막도 클릭해서 오역을 비공개로 신고할 수 있습니다.

**영상 용량만 정리:** 완료된 YouTube 작업의 **임시 영상 삭제 (MB)**는 프로그램이 받은 화면 분석용 영상과 영상 저장용 사본만 삭제합니다. 자막·수정 내용·작업 기록·따로 다운로드한 파일은 보존합니다. YouTube에서 자막을 계속 볼 수 있고, 영상 저장을 다시 누르면 새로 다운로드합니다.

## 자막·영상 저장과 수정

음성·화면 자막의 배경은 확장 설정과 미리보기에서 각각 켜고 끌 수 있습니다. 배경 설정은 감상용이며 다운로드 파일의 스타일을 바꾸지 않습니다.

- 음성 자막에 마우스를 올리면 나타나는 **↕ 이동** 손잡이를 위아래로 끌면 모든 음성 자막의 높이가 함께 바뀝니다. 클릭하면 기존 신고·삭제 메뉴가 열립니다. 확장 설정이나 미리보기의 **음성 자막 높이 / 기본 위치**로도 조절할 수 있습니다. 높이는 연결된 작업에 자동 저장됩니다. VTT·프로젝트 JSON에는 조절한 위치가, SRT에는 내용·시간만 반영됩니다. 문구 수정도 다운로드 전에 저장됩니다. 재생바가 보일 때에는 겹친 화면 번역의 해당 부분만 클릭을 통과시켜 재생 조작을 우선합니다. 자막의 나머지 부분은 계속 클릭할 수 있습니다.

- 저장 대상의 기본값은 **음성 자막 + 화면 자막**입니다. **음성 자막만 / 화면 자막만**도 선택할 수 있습니다. SRT·VTT는 일반 자막용, 프로젝트 JSON은 화면 위치까지 보존해 확장에서 불러올 때 사용합니다.
- 번역 목록이나 영상 위의 자막을 클릭해 **삭제·오역 신고**를 할 수 있습니다. 삭제한 자막은 **삭제한 자막** 탭에서 복원합니다. 신고는 GitHub 로그인 없이 비공개로 접수됩니다.
- 완료된 유튜브 작업의 **유튜브 영상 저장 ↓**로 영상을 따로 저장할 수 있습니다. 자막은 별도 파일로 저장하세요.
- **작업 기록 삭제**는 프로그램 안의 해당 영상·음성 사본과 생성·중간 파일도 정리합니다. PC 원본과 별도로 다운로드한 영상·자막은 유지합니다.

## API 설정과 업데이트

Gemini·OpenAI·DeepL API Free/Pro·Ollama를 지원합니다. **2026-10-19 한국시간 작성 기준 무료 API 추천**은 [Google AI Studio](https://aistudio.google.com/apikey)의 **Gemini 3.1 Flash-Lite**(<code>gemini-3.1-flash-lite</code>)이며, 계정·프로젝트의 [무료 조건과 한도](https://ai.google.dev/gemini-api/docs/pricing)를 확인하세요. Ollama는 별도 설치·모델 준비가 필요합니다.

키를 바꾸려면 **왼쪽 메뉴 → API 및 연결 설정**에서 저장하세요. 키는 본인 PC에 보관합니다. 프로그램 업데이트와 **용어집 업데이트**도 이 설정 화면에서 확인할 수 있습니다.

**확장 업데이트는 수동 새로고침이 필요합니다.** 앱 안에서 프로그램 업데이트를 마친 뒤, Chrome은 주소창에 `chrome://extensions`, Edge는 `edge://extensions`를 입력합니다. ZZZ 확장 카드의 **↻ 새로고침**을 누르고 유튜브 페이지에서 **F5로 새로고침**한 뒤, 확장을 열어 **선택한 자막 적용**을 다시 누르세요. ZIP을 **다른 폴더에 새로 풀었다면** 이전 폴더를 보는 확장을 끄고, 새 폴더 안의 **video-extension**을 **압축해제된 확장 프로그램 로드**로 불러온 뒤 **PC 연결 코드**를 다시 등록하세요.

같은 폴더에 업데이트했다면 브라우저를 완전히 종료 후 다시 열거나 컴퓨터를 재시작해도 새 확장 파일을 불러옵니다. 이후 유튜브 페이지를 새로고침하고 자막을 다시 적용하세요.
