# ZZZ字幕工作室

[한국어](README-ko.md) · [English](README-en.md) · [日本語](README-ja.md) · [简体中文](README-zh-CN.md)

选择YouTube视频或本地文件，完成识别和翻译后，再使用生成的字幕观看。适用于Windows电脑。

**[下载Windows x64版 · 0.7.2](https://github.com/Odarom/zenless-subtitle-studio/releases/download/v0.7.2/zenless-subtitle-studio-0.7.2-win-x64.zip)** · [最新发布页面](https://github.com/Odarom/zenless-subtitle-studio/releases/latest)

## 安装并制作字幕

1. **完整解压**ZIP，运行**Start.cmd**。已包含Node.js。首次运行会下载语音、视频工具及模型，需要联网并等待准备完成。
2. 在浏览器打开的**ZZZ字幕工作室**左侧菜单选择**API 与连接设置**，填写服务、模型及自己的API密钥并保存。
3. 在**翻译视频**中输入YouTube地址，或选择视频、音频、SRT/VTT文件，再选择原文和目标语言。
4. 选择识别选项。**不使用YouTube字幕，从音频重新生成**默认开启，屏幕文字识别OCR默认关闭。选择**仅保存原文字幕，不翻译**时，不会调用翻译API。
5. 点击**生成字幕**并等待完成，检查译文后保存或应用到视频。

**工作室**指运行Start.cmd后在浏览器打开的程序页面。使用期间请保持程序运行窗口开启。处理在自己的电脑上进行，无需另外的视频处理服务器。

## 举报误译，帮助改进翻译质量

发现游戏术语、缩写或翻译错误？我们会审核举报，用于改进绝区零游戏术语数据库和翻译质量。

1. **YouTube或本地视频预览：** 点击语音字幕或屏幕翻译，选择**举报误译**。YouTube需先连接PC工作室并应用已完成的任务。
2. **字幕列表：** 在已完成任务的**检查并编辑字幕**中选择**语音字幕 / 画面文字**，点击对应片段的**举报误译**。
3. 说明错误并点击**发送举报**。正确译法建议为选填。显示**接收编号**表示发送成功。

不知道正确译法也可以指出错误部分。举报为非公开，无需登录GitHub。

不使用程序也可[直接举报官方名称或缩写错误](https://github.com/Odarom/zenless-translation-database/issues/new/choose)。此GitHub举报方式需要账号，内容会公开。

## 翻译并预览自己的视频文件

无需YouTube链接，也可以翻译**自己的视频文件，并在预览时修改字幕、举报误译**。推荐结合实际画面检查翻译。

1. 在**翻译视频 → 导入文件**选择自己的视频，完成翻译。
2. 在已完成的任务中点击**用本地视频预览字幕**，选择**翻译时使用的同一个原始视频**。
3. 点击语音字幕或屏幕译文，会暂停播放并打开**删除字幕、举报误译**菜单。**文字修改请在预览下方“检查并编辑字幕”的译文输入框中进行**，修改会立即显示在预览中。
4. 确认后点击**保存 VTT ↓**或**项目 JSON ↓**，保存修改内容和调整后的语音字幕位置。**保存 SRT ↓**仅包含内容和时间。下载前也会保存尚未保存的文字修改。

预览自己的视频不需要安装YouTube扩展。如果浏览器无法播放该格式，请在外部播放器中对照视频和字幕，并在工作室字幕列表中修改或举报。

## 在YouTube观看字幕

1. 在Chrome/Edge扩展管理页开启**开发者模式 → 加载已解压的扩展程序**，选择随包提供的**video-extension**文件夹。
2. 在**工作室左侧菜单 → API 与连接设置 → 连接 YouTube 扩展程序**点击**复制本机连接码**。
3. 打开YouTube视频，点击浏览器右上方的**ZZZ字幕工作室扩展图标**，将代码粘贴到**本机连接码**并点击**连接**。这里不是填写翻译API密钥的地方。
4. 在**已完成字幕**选择对应视频任务，点击**应用所选字幕**。

## 共享字幕档案馆

在[共享字幕档案馆](https://odarom.github.io/zenless-subtitle-studio/archive/)查找视频，点击 **在YouTube观看（需扩展）**。字幕仅应用于登记的原作者YouTube视频。档案馆不提供嵌入播放或字幕下载。

**仅观看时：**解压ZIP，在Chrome/Edge加载 **video-extension** 文件夹即可。**无需运行Start.cmd、连接PC工作室、填写翻译API密钥或登录Google。** 请重新加载0.7.0或更新版本的扩展，并刷新YouTube页面。

**分享时：**在PC工作室已完成的YouTube任务详情或 **任务记录卡片**中选择 **分享到档案馆**，确认显示设置并同意公开。尚未保存的字幕修改及位置会先保存。公开内容包括字幕、原视频信息和显示设置，不包含视频文件、API密钥及PC路径。请仅分享有权发布的字幕。[隐私说明](https://odarom.github.io/zenless-subtitle-studio/archive/privacy.html#zh-CN)

在原PC选择 **取消共享** 可撤下帖子。删除本地记录不会取消公开，请 **先取消共享**。已经传送的字幕无法收回，也无法阻止复制。观看者的编辑或隐藏不会更改原共享文件。点击共享字幕也可发送非公开误译举报。

**仅清理视频空间：**已完成的YouTube任务中的 **删除临时视频（MB）** 只删除程序的画面分析视频与视频保存副本。字幕、修改、任务记录及单独下载的文件将保留。仍可在YouTube观看字幕；再次保存视频时会重新下载。

## 保存与编辑

可在扩展设置和预览中分别开关语音字幕和屏幕字幕背景。这些观看设置不会改变下载文件的样式。

- 将鼠标移到语音字幕附近，拖动出现的 **↕ 移动** 手柄可同时调整所有语音字幕的高度。点击字幕仍会打开举报和删除菜单。扩展设置和预览中的 **语音字幕高度 / 重置位置** 也可调整。高度会自动保存到已连接的任务中。VTT和项目JSON会保留调整的位置，SRT仅保存内容和时间。下载前也会保存文字修改。播放器控件显示时，屏幕字幕仅在重叠区域让点击穿透到播放控件，其余部分仍可点击。

- 默认保存**语音字幕 + 屏幕字幕**，也可选择**仅语音 / 仅屏幕**。SRT/VTT用于普通字幕；项目JSON保留屏幕位置，可在扩展中导入。
- 点击检查列表或视频上的字幕，可以**删除或举报误译**。删除内容可在**已删除字幕**中恢复。举报私下接收，无需GitHub登录。
- 完成的YouTube任务提供**保存YouTube视频 ↓**，字幕请另存为文件。
- **删除任务记录**也会清理程序内为该任务保存的视频、音频副本及生成、中间文件。电脑原文件和另行下载的视频、字幕保留。

## API设置与更新

支持Gemini、OpenAI、DeepL API Free/Pro及Ollama。**韩国时间2026-10-19记录的免费API推荐**为[Google AI Studio](https://aistudio.google.com/apikey)的**Gemini 3.1 Flash-Lite**（<code>gemini-3.1-flash-lite</code>），请确认账户、项目的[免费条件和配额](https://ai.google.dev/gemini-api/docs/pricing)。Ollama需另行安装并准备本地模型。

更换密钥请在**左侧菜单 → API 与连接设置**保存。密钥保存在自己的电脑。同一设置页面可检查程序和术语库更新。

**扩展需要手动重新加载。** 在应用内完成程序更新后，Chrome请打开 `chrome://extensions`，Edge请打开 `edge://extensions`，点击ZZZ扩展卡片的 **↻ 重新加载**，然后按 **F5 刷新YouTube页面**，并在扩展中再次点击**应用所选字幕**。如果将新ZIP解压到**不同的文件夹**，请停用使用旧文件夹的扩展，通过**加载已解压的扩展程序**选择新目录内的 **video-extension**，并重新登记**本机连接码**。

若更新至同一文件夹，也可完全退出并重新打开浏览器，或重启电脑，以加载新的扩展文件。之后请刷新YouTube页面并重新应用字幕。
